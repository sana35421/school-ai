# 校园智能问答助手 · 完整部署指南

> 适用对象：0 基础小白也能照着做的保姆级教程。

## 一、准备阶段

### 1.1 安装 Docker Desktop（Windows）

1. 访问 https://www.docker.com/products/docker-desktop/
2. 下载并安装（需要 Windows 10/11 专业版或教育版）
3. 安装后重启电脑
4. 打开 Docker Desktop，等待右下角图标变绿

### 1.2 安装必备开发工具

| 工具 | 下载地址 | 用途 |
|------|----------|------|
| JDK 17 | https://adoptium.net/ | 后端运行环境 |
| Maven | https://maven.apache.org/ | 后端构建 |
| Node.js 18+ | https://nodejs.org/ | 前端开发 |
| VS Code | https://code.visualstudio.com/ | 代码编辑 |
| IntelliJ IDEA (Community) | https://www.jetbrains.com/idea/ | 后端开发（推荐）|

## 二、Dify 部署与配置

### 2.1 部署 Dify

```bash
# 在 D:\school-ai\ 下创建 dify 目录
mkdir D:\school-ai\dify
cd D:\school-ai\dify

# 克隆官方仓库
git clone https://github.com/langgenius/dify.git .

# 复制环境变量模板
cp .env.example .env

# 启动
docker compose up -d
```

浏览器访问 `http://localhost/install`，设置管理员账号。

### 2.2 配置 DeepSeek 模型

1. 进入 Dify 控制台 → **设置** → **模型供应商**
2. 找到 **DeepSeek**，点击「安装」
3. 填入 API Key（在 https://platform.deepseek.com/ 申请）
4. 测试连接成功

### 2.3 创建知识库

1. 顶部菜单 → **知识库** → **创建知识库**
2. 数据源选 **导入已有文本**
3. 上传文档（建议 PPT 先转 PDF）：
   - 学科竞赛政策文件
   - 奖学金评定办法
   - 保研推免流程
   - 学生手册
   - 常见 Q&A
4. 文本分段：**通用模式**（推荐）或 **父子分段**
5. 索引模式：**高质量**
6. Embedding 模型：**BGE**
7. 点 **保存并处理**，等索引完成

### 2.4 创建聊天助手

1. 顶部菜单 → **工作室** → **创建空白应用** → **聊天助手**
2. 关联上面建的知识库
3. 编排 Prompt：

```
你是一名校园智能助手，负责回答学生关于学科竞赛和学校政策的疑问。

要求：
1. 优先从关联知识库中查找答案，给出准确的政策依据。
2. 用简洁、清晰、分点的形式回答。
3. 如果知识库没有相关信息，礼貌告知并建议联系导员或查阅学校官网。
4. 不要编造政策或时间节点。
5. 回答结尾引用相关文档来源。
```

4. 点 **发布**，记下右上角的 **API Key**（格式 `app-xxx`）

### 2.5 验证 Dify API

```bash
curl -X POST "http://localhost/v1/chat-messages" ^
  -H "Authorization: Bearer app-你的APIKey" ^
  -H "Content-Type: application/json" ^
  -d "{\"inputs\":{},\"query\":\"蓝桥杯是什么竞赛\",\"response_mode\":\"blocking\",\"user\":\"test\",\"conversation_id\":\"\"}"
```

## 三、数据库准备

### 3.1 启动 MySQL

如果用 docker compose 一键启动，MySQL 会自动跑起来，初始数据也会自动导入。

如果手动启动：

```bash
docker run -d --name mysql ^
  -e MYSQL_ROOT_PASSWORD=root123 ^
  -e MYSQL_DATABASE=school_ai ^
  -p 3306:3306 ^
  -v mysql_data:/var/lib/mysql ^
  mysql:8.0
```

### 3.2 导入初始化脚本

```bash
docker exec -i mysql mysql -uroot -proot123 < D:\school-ai\db\init.sql
```

或在 Navicat / MySQL Workbench 中执行 `db/init.sql`。

## 四、后端启动

### 4.1 修改配置

编辑 `backend\src\main\resources\application.yml`：

```yaml
dify:
  api-base: http://localhost/v1
  api-key: app-你的DifyKey  # ← 改成 2.4 步拿到的 API Key

jwt:
  secret: 请改成复杂的随机字符串
```

### 4.2 启动方式

**方式 A：IDEA**
1. 用 IDEA 打开 `backend` 目录
2. 等待 Maven 依赖下载完成
3. 启动 `SchoolAiApplication`

**方式 B：命令行**

```bash
cd D:\school-ai\backend
mvn spring-boot:run
```

看到 `Started SchoolAiApplication in 5.x seconds` 表示成功。

### 4.3 测试后端

```bash
curl http://localhost:8080/api/auth/login -X POST ^
  -H "Content-Type: application/json" ^
  -d "{\"studentId\":\"20220101\",\"password\":\"123456\"}"
```

应该返回 token。

## 六、生产部署（Docker Compose 一键）

```bash

等待所有服务启动（约 1-2 分钟），访问 `http://localhost`

```

## 七、常见问题

### Q1: 前端登录后接口 401？

检查后端日志，确认 JWT 签名密钥一致。

### Q2: Dify 报错 "API key invalid"？

到 Dify 控制台 → 应用 → API 访问，重新生成 Key 复制到 `application.yml`。

### Q3: AI 回答没有引用知识库？

- 确认知识库索引处理完成
- 确认聊天助手已关联知识库
- 在 Prompt 中明确要求"必须基于知识库回答"

### Q4: SSE 流式输出断开？

检查 Nginx 配置，确认 `/api/` 路径添加了：
```
proxy_buffering off;
proxy_cache off;
proxy_read_timeout 300s;
```

### Q5: Docker 启动 MySQL 失败？

Windows 上需要先在 Docker Desktop 设置中开启 WSL2 后端。

## 八、上线后的运维

1. **数据库备份**：每天凌晨自动 mysqldump 到 OSS
2. **日志收集**：用 Loki + Grafana 收集 Docker 日志
3. **监控告警**：用 UptimeRobot 监控 `http://your-domain/api/health`
4. **HTTPS**：用 Let's Encrypt + Certbot 自动签发证书
5. **定期清理**：每周跑一次脚本清理 7 天前的 messages

```sql
DELETE FROM messages
WHERE conversation_id IN (
    SELECT conversation_id FROM conversations
    WHERE last_active_at < DATE_SUB(NOW(), INTERVAL 7 DAY)
);
DELETE FROM conversations WHERE last_active_at < DATE_SUB(NOW(), INTERVAL 7 DAY);
```
